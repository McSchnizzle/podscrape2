## Key Changes Summary

### Before (Brittle stdout parsing)
```python
# Orchestrator had ~175 lines of complex JSON parsing:
# - Real-time streaming with JSON detection
# - Multi-line JSON accumulation in buffer
# - Multiple fallback strategies searching stdout
# - O(n^2) worst-case with multi-line scanning
```

### After (Deterministic file-based contract)
```python
# Create temp file for JSON output
with tempfile.NamedTemporaryFile(mode='w', suffix='.json', delete=False) as tf:
    output_json_path = tf.name

# Pass --output-json flag to phase script
cmd.extend(['--output-json', output_json_path])

# Read result from file (deterministic!)
from src.utils.phase_output import read_phase_result
json_output = read_phase_result(output_json_path)
```

### Benefits
1. **Deterministic**: JSON always read from file, never parsed from stdout
2. **Clean separation**: Logs go to stdout, JSON goes to file
3. **Simpler code**: Removed ~100 lines of complex parsing logic
4. **Backward compatible**: If `--output-json` not specified, scripts still output to stdout
5. **Consistent**: All 6 phase scripts use same `write_phase_result()` utility
